# 导演、摄影、灯光与表演决策

本文件是针对本用户工作流的创作建议，不是模型的确定性控制保证。按场景需要选择，不要求全部术语进入提示词。

## 从戏剧任务选镜头

| 当前任务 | 优先考虑 | 必须检查 |
| --- | --- | --- |
| 交代谁与谁、谁能看见什么 | 全景或双人中景，稳定机位 | 门、道具与人物距离可读 |
| 试探、隐瞒、权力平衡 | 双人中景或过肩，固定或小幅跟随 | 谁占前景、谁占更多空间有剧情依据 |
| 发现信息、做出决定 | 中近景到近景；固定或缓慢推进 | 推进由信息变化触发，结束前稳定 |
| 对白中的真实反应 | 选择听者反应而非逐句机械正反打 | 听者反应发生在听到信息之后 |
| 证据必须可读 | 道具插入镜头，或双人景中明确可见 | 尺寸、焦点、遮挡；文字必要时后期制作 |
| 孤立、疏离 | 保留环境的中全景或拉远 | 不能拉远后仍把细微眼神作为关键叙事证据 |
| 靠近、离开、追赶 | 动作可读的中全景、跟拍 | 运动方向、步态、落脚和出入画位置 |
| 时间地点改变 | 新场景完整单元与清楚的剪辑连接 | 不强行伪装成同一条生成长镜头 |

同一场不强制先全景：悬念可以先拍局部，但应在需要时补齐空间信息。固定、推拉、手持的比例不硬编码；类型、节奏与实际生成稳定性决定比例。

## 摄影机与焦点

每次运动定义六项：起始构图、终止构图、运动路径、速度变化、主体相对位置、停止或接镜时机。

- 固定：镜架稳定；角色可以动。固定机位不等于人物冻结。
- 推/拉：摄影机在空间中移动，前后景关系随之改变。需要说明靠近谁、停在哪个景别。
- 变焦：改变画面取景范围，不把它误写成摄影机前进。推镜与变焦不能含糊混用。
- 横摇/俯仰：摄影机位置基本固定、方向旋转；目标是跟随或揭示。写清起止对象。
- 跟移：摄影机与人物共同移动；写清在前、后、侧方以及保持的相对距离感。
- 环绕/升降：只在空间揭示或关系变化需要时使用；核对遮挡、轴线变化和背景重建负担。
- 手持：描述克制或强烈程度；情绪场面不默认持续漂浮抖动。
- 转焦：与摄影机运动分开记录。焦点从什么转到什么，观众何时应看清；没有必要时稳定焦点。

数值焦段仅为视觉参考，画面效果还受机位距离和成像幅面影响。不要暗示写“85mm、T1.4、ARRI”即可得到准确光学模拟。优先用实际可见的透视、景别、背景清晰度说明效果。

## 16:9构图与连续性

- 用横向空间呈现关系：人物间距、空位、前后景、门框或桌缘都可承担信息。
- 眼睛与关键道具保持可读；头顶、手部动作边界与字幕区域提前检查。
- 建立场景坐标，例如门北、窗西、女主坐西侧、男主坐东侧。正反打使用同一侧机位区，必要的越轴用可读的连续移动或重新建立镜头解释。
- “过肩”是构图关系，不是高度角；仍需说明平视/俯视/仰视。镜像翻转不是修复轴线的默认办法，可能改动惯用手和道具方向。
- 动作接镜从可匹配的运动阶段切换，不重复伸手或跳过接触。反应接镜保持目光对象和情绪发展；省略时间时明确这是时间跳切。
- 上一镜尾帧可作为同机位续接参考，但先检查变形。换机位时用尾帧核对状态，再制作新视角首帧，不能直接把原尾帧当反打首帧。

## 光影方案

每场先定义“时间/天气＋世界中的光源位置＋光质＋反差＋白平衡倾向”，每镜再从该机位推导画面效果。

| 情境 | 可选方案 | 质量重点 |
| --- | --- | --- |
| 日间室内真实文戏 | 窗侧柔光，墙面自然回光 | 面部层次、肤色自然、阴影不漂移 |
| 夜间私密对话 | 台灯/走廊等实景光作动机，柔和补足脸部 | 暖光有来源，暗部仍能读懂表演 |
| 悬疑对峙 | 有方向的侧光、控制环境亮度 | 不为了黑而丢失关键动作或表情 |
| 阴天室外 | 大面积天空柔光 | 衣服、皮肤与背景分离，避免全画面发灰 |
| 夜外/霓虹 | 限定少数可见光源颜色 | 防止肤色被无目的染色、招牌闪烁 |
| 回忆或梦境 | 与现实段建立可读差异 | 风格变化来自叙事，不是逐镜随机滤镜 |

区分光源色温与后期调色。反打后不照抄“画面左侧光”；世界光源位置不变，但画面左右可能变化。保留皮肤纹理、高光层次与眼神可见度；浅景深、逆光、轮廓光、雾、颗粒均非必填。

## 人物状态与细微表演

先写内在状态供导演判断，再转换成可见行为给模型。角色不知情时不能提前露出“看穿真相”的反应。

表演卡字段：
触发事件｜角色已知信息｜当下目标｜试图掩饰什么｜身体基线｜目光目标｜一项主要反应｜可选细节｜动作幅度｜结束状态。

例子为表演选择，不是固定心理学对应关系：

- 想否认但需要时间：视线短暂停在物证，吸气后才抬头；避免同时握拳、流泪、颤抖。
- 委屈但不愿示弱：下颌略收紧，先看向侧方，再恢复目光；不必立刻落泪。
- 试探对方：完成一句话后保持视线，留出观察对方反应的停顿。
- 受到惊吓：先短暂停顿，再改变呼吸或后撤；依据具体动作与人物性格选择。
- 情绪释放：一个清楚的动作或声音变化即可，不把所有强反应同时堆叠。

远景：重心、步速、朝向、距离。中景：手部、肩颈、姿态与视线。近景：眼睑、嘴角、下颌和呼吸。大特写：只在细节承载信息且模型能稳定表现时使用。

所谓微表情按“短暂、克制、可见的表情变化”处理；不承诺精确到某块肌肉、某一帧或心理真实性。对白长、遮挡重、多人互动时先保住动作与嘴型，减少多余细节。

## 风险降级而不丢叙事

手部交互失败：简化持物姿态、让桌面支撑物体、降低并行动作，或另设完整道具单元；不能偷偷删掉关键交付动作。

多人对白失败：按发言和反应分配机位，保留同场关系参照；声音可以跨剪辑延续，但不让未发言者乱动嘴。

复杂长镜头失败：沿动作自然节点拆为两个4—15秒单元，匹配姿态、运动方向和接触状态。

微表情不可读：调整景别或减少遮挡，不能只在提示词里反复加“细腻”。

光影漂移：先修场景参考与机位图，保持少数明确光源，再处理色温；调色无法替代光源逻辑。
