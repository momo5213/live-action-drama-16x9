# 模型适配与能力边界

默认平台中立，不自动安装软件、不指定供应商、不默认生成视频。仅写提示词不能证明已输出视频。用户指定工具后，使用当前可用连接器或官方入口；无相应工具则交付可粘贴提示词与设置。

## 使用前核对

| 字段 | 核对要求 |
| --- | --- |
| 名称/版本/入口 | 同品牌的网页、API、第三方转接能力可能不同 |
| 画幅 | 确认16:9实际设置，不能仅依靠文字 |
| 时长 | 使用该入口的明确档位，与4—15秒整数取交集 |
| 参考机制 | 身份参考、首帧、尾帧、运动参考不是同一种能力 |
| 声音 | 是否原生对白、可指定语言、可输入音轨、支持口型；不凭产品名推断 |
| 输出 | 原生分辨率、帧率、是否后期放大、文件规格 |
| 约束方式 | 是否有负面输入框、相机参数或分镜结构；无则用自然语言 |

记录官方依据链接和查询日期。变化快的参数在实际使用时重新验证；本文件不是2026年所有平台的能力清单。

## 已核实的提示原则

### Runway Gen-4（官方指南的明确适用范围）

官方建议高质量起始图、简单直接的动作描述、正向表述与逐项迭代；该指南记载5秒和10秒生成档位。不将这个时长表推广到所有Runway型号或其他入口。

来源：[Gen-4 Video Prompting Guide](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)。核对：2026-09-10。

### Runway图生视频指南

图片承担主体、构图、光线与风格信息；提示词重点表达运动、方向、速度和时间进程。当前查阅的指南说明针对Gen-4.5优化。时间轴用于制作规划，给模型时可以写成自然动作次序，避免逐秒堆满事件。

来源：[Image to Video Prompting Guide](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)。核对：2026-09-10。

### Veo提示原则

官方指南涵盖构图/运镜、人物、动作、光线、地点、对白与声音。文生场景可给足必要的视觉和声音信息，不能误套“所有长提示词都不好”。具体参考能力和时长仍以用户入口为准。

来源：[Veo Prompt Guide](https://deepmind.google/models/veo/prompt-guide/)。核对：2026-09-10。

### 可灵、Seedance、海螺及其他

本skill未预先验证这些工具每个型号/入口的全部规格。先用官方资料核对用户当前版本，再编译同一镜头的模型版提示词。不复制第三方仓库“某型号最强/某型号已停用”的表述作为官方事实。

## 降级规则

- 不支持目标档位：在支持的4—15秒整数档位重新安排节奏与使用区间，不偷偷修改剧本事实。
- 不支持尾帧：把结束状态写清；实片检查后选择可用结尾，不能承诺首尾精确命中。
- 不支持身份参考：交付参考素材需求与可尝试方式，将人物一致性列为待实片验证。
- 不支持声音：对白与音效移入后期卡，视频正文不要求设备不存在的音频功能。
- 只支持文生：提示词补充固定外观和场景；把跨镜头漂移列为样片重点。
- 实际生成有成本：沿用用户已明确的预算/次数；未授权生成时不因skill流程自动消费。连续失败时检查输入与动作复杂度，不能无限重试。
